# SRGI Lucknow Production RAG Knowledge Package (Release V3)
============================================================

This package contains the finalized, production-engineered, source-grounded institutional knowledge database for **S. R. Group of Institutions (SRGI), Lucknow**, generated by the Universal Knowledge Ingestion Engine.

- **Institution Identifier:** `srgi_lucknow`
- **Canonical Website:** `https://srgi.in`
- **Release Version:** `v3.0.0`
- **Release Status:** `PRODUCTION_VALIDATED`

## Directory Structure
- `documents/`: 55 canonical Markdown documents and 55 matching companion Word DOCX documents organized into 15 dynamic subject categories.
- `metadata/`: 55 per-document JSON metadata sidecars providing cryptographic hashes, source URLs, and entity tags.
- `data/`: 19 canonical institutional configuration JSON datasets (academic programmes, contacts, locations, hostels, transport, etc.).
- `source_registry/`: Complete URL inventory, source manifest, exclusions/quarantine register, lineage maps, and conflict register.
- `reports/`: Complete validation reports, claim-level evidence ledger, chunk-readiness audit, and acceptance reports.
