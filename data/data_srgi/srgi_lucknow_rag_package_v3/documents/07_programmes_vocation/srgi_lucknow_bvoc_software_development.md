# B.Voc in Software Development

## Scope
Software Development vocational degree, sanctioned intake of 90 seats, HTML/CSS/JavaScript, database management, full-stack application projects.

## 1. Programme Specification
- **Degree:** Bachelor of Vocation in Software Development
- **Sanctioned Annual Intake:** 90 Seats
- **Duration:** 3 Years (6 Semesters)

## 2. Practical Training Curriculum
- Frontend Engineering (HTML5, CSS3, JavaScript, React basics)
- Backend & Database Management (Python, Node.js, SQL, MongoDB)
- Software Testing, Quality Assurance & Debugging
- Version Control (Git/GitHub) and Cloud Deployment

## 3. Career Roles
Junior Software Developers, Web Developers, QA Automation Testers, Technical Support Specialists.
