# Central Library System and Digital Knowledge Repositories

## Scope
Central Library collection of 53,760+ books, 448+ journals, 13,440 sq. ft. area, Techlib-7 software, OPAC, NDL, DELNET, and Sugamya Pustakalaya access.

## 1. System Architecture
The SRGI Library System comprises the **Central Library** and two specialized departmental libraries, providing comprehensive bibliographic and digital support across engineering, management, medical sciences, and humanities.

## 2. Key Library Metrics

| Feature | Institutional Specification |
| :--- | :--- |
| **Physical Books Collection** | 53,760+ Volumes |
| **Subscribed Journals & Periodicals** | 448+ National and International Titles |
| **Dedicated Library Floor Area** | 13,440+ Square Feet |
| **Students Served Annually** | 4,480+ Active Members |
| **Library Management Software** | Techlib-7 Automated System |
| **Catalog Access** | Online Public Access Catalogue (OPAC) Terminals |

## 3. Digital Consortia & Memberships
- **National Digital Library of India (NDL):** Institutional membership granting access to millions of digital manuscripts, books, and lecture archives.
- **DELNET (Developing Library Network):** Inter-library loan services and access to union catalogues across Indian universities.
- **Sugamya Pustakalaya:** Specialized accessible digital repository for visually impaired students.
- **E-Learning Portals:** Dedicated terminals accessing NPTEL, SWAYAM, KNIMBUS, and FOSSEE repositories.
